Pre-Condition:

The user must be logged in with his credentials and has selected a project from the homepage. Also there must exist at least one use case.

Main flow:

The use case begins when the user has picked a project and has added at least one use case to this project.
To delete a use case, the user clicks the edit button, which is located at the top right of the use case, and selects the delete option from the drop down menu.
The system pops up a confirmation window, “Are you sure you want to delete this use case?”
2.1 If the user picks “yes”, the system deletes the use case.
2.2 If the user picks “no”, the system closes the pop up confirmation window.
